LNCHS error pages

Every error page the portal can show, and what it means.

CodeNameMeaning
400Bad RequestThe server could not understand the request. The address or the information sent was incomplete or damaged.
401Sign In RequiredThis page needs you to sign in first, or your sign-in details were not accepted.
403Access DeniedYou are not allowed to open this page. It may be for staff only, or your account does not have permission.
404Page Not FoundWe could not find the page you asked for. It may have moved, been removed, or the address may have a typo.
405Method Not AllowedThis page does not accept the way the request was sent. This usually happens when a form or link is opened in a way it was not meant to be.
408Request TimeoutThe connection was too slow, so the server stopped waiting for your request to finish.
410Page RemovedThis page used to exist but was removed on purpose, and it is not coming back.
413File Too LargeWhat you tried to send is bigger than the server allows.
414Address Too LongThe web address you used is too long for the server to handle.
429Too Many RequestsYou sent a lot of requests in a short time, so the server asked you to slow down.
500Internal Server ErrorSomething went wrong on our side while handling your request. It is not your fault.
501Not ImplementedThe server does not support what you asked it to do.
502Bad GatewayOne part of the server got a bad answer from another part. This is usually temporary.
503Service UnavailableThe portal is busy or down for maintenance right now. This is usually temporary.
504Gateway TimeoutThe server waited too long for another part of the system to answer.
